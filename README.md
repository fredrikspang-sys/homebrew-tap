# Homebrew tap

Formulae and casks for software by [Fredrik Spång](https://github.com/fredrikspang-sys).

## Nightdeck

A native macOS player for BluOS.

```sh
brew install --cask fredrikspang-sys/tap/nightdeck
```

The app is ad-hoc signed and not notarized, so macOS may block it the first time. See the [Nightdeck README](https://github.com/fredrikspang-sys/nightdeck#download-and-install) for how to open it.
